# ใช้คู่มือ BEST → FlowAccount ใน Codex Cloud

ไฟล์ Skill: `.agents/skills/best-flowaccount-tracking/SKILL.md`

เปิด Codex Cloud เลือกสภาพแวดล้อม CHOK และ branch `main` จากนั้นเริ่มงานใหม่เพื่ออ่านไฟล์ล่าสุด

## ตรวจว่าอ่าน Skill ได้

สั่งว่า:

```text
อ่าน .agents/skills/best-flowaccount-tracking/SKILL.md
สรุปกฎจับคู่บิล การเก็บโน้ตเดิม และการป้องกันเลขซ้ำ
ตรวจว่ามีเครื่องมือเบราว์เซอร์และเข้าถึง BEST กับ FlowAccount ได้หรือไม่
ยังไม่ต้องแก้บิล
```

## สั่งทำงานเมื่อเครื่องมือพร้อม

```text
ใช้ $best-flowaccount-tracking
นำเลขพัสดุ BEST ช่วง [วันเริ่มต้น] ถึง [วันสิ้นสุด]
ไปเพิ่มในโน้ตภายในบริษัทของบิล [ประเภทเอกสาร] ใน FlowAccount
รวมหลายเลขต่อบิลตามหลักฐาน เก็บโน้ตเดิม และเพิ่มเฉพาะเลขที่ขาด
เปิดตรวจหลังบันทึก หากจับคู่ไม่ชัดเจนให้เว้นรายการนั้นและรายงาน
```

เปลี่ยนช่วงวันที่ทุกครั้ง คู่มือเดิมไม่ใช่คำสั่งให้กรอกข้อมูลซ้ำ

## ขอบเขตที่พร้อมใช้งาน

- Repo มีคู่มือและ Skill ให้ Codex Cloud อ่านได้
- การกรอกบิลต้องมีเครื่องมือเบราว์เซอร์และ session ที่เข้าสู่ระบบ BEST กับ FlowAccount จริง การเพิ่ม Skill ไม่ได้เชื่อมแท็บ Chrome บนเครื่องส่วนตัว
